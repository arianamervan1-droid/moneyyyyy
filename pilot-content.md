## 2. Sample week — 3-day full-body plan (beginner)

Warm-up (5 min, every session): easy walk or bike, then 1 light set of the first exercise.
Effort: finish each set feeling you could do about 2 more reps. Rest 60–90 s between sets.
Progression: when you hit the top of the rep range on every set for two sessions in a row, add the smallest weight increase available.

| Day | Exercise | Sets × reps | Cue |
|---|---|---|---|
| **Mon (A)** | Goblet squat | 3 × 8–10 | Elbows inside knees, chest tall, heels down |
| | Machine or dumbbell chest press | 3 × 8–10 | Shoulder blades back, controlled lowering |
| | Seated cable row | 3 × 10 | Pull elbows toward ribs, don't shrug |
| | Dumbbell Romanian deadlift | 2 × 10 | Hips back, soft knees, flat back |
| | Plank | 2 × 20–30 s | Ribs down, squeeze glutes |
| **Wed (B)** | Leg press | 3 × 10–12 | Feet shoulder-width, don't lock knees |
| | Lat pulldown | 3 × 8–12 | Pull to upper chest, lean back slightly |
| | Dumbbell shoulder press | 2 × 10 | Ribs down, don't arch hard |
| | Glute bridge or hip thrust | 3 × 10 | Pause 1 s at top |
| | Dead bug | 2 × 8 per side | Low back stays flat |
| **Fri (C)** | Step-up or split squat | 3 × 8 per side | Use the front leg, slow down |
| | Incline push-up or machine press | 3 × 8–12 | Body in a straight line |
| | One-arm dumbbell row | 3 × 10 per side | Hand on bench, flat back |
| | Cable face pull | 2 × 12–15 | Light weight, elbows high |
| | Farmer carry | 3 × 30 s | Tall posture, steady breathing |

**Swaps (easier / equipment taken / feels uncomfortable):**
- Goblet squat → box squat to a bench · Leg press → bodyweight sit-to-stand
- Chest press → incline push-up on a bench · Shoulder press → landmine or seated machine press
- Lat pulldown → assisted pull-up machine (lighter) · Cable row → chest-supported row
- Romanian deadlift → hip hinge with a dowel, then light dumbbells · Step-up → lower step or split squat holding a rail
- Plank → incline plank on a bench · Dead bug → bent-knee heel taps

**4-day option (upper/lower):** Mon Lower · Tue Upper · Thu Lower · Fri Upper, using the same movements split by body area, 3 sets each, one fewer accessory per day. Pick this only if you can show up 4 times a week.

If something causes sharp pain, stop that exercise, use the swap, and talk to a qualified medical professional if it continues.

## 3. Onboarding questions (start form)

1. First name and email
2. Days per week you can realistically train (2 / 3 / 4)
3. Which days work best?
4. Have you used a gym before? (Never / A little / Used to go)
5. Which equipment can you use? (Machines / dumbbells / cables / barbells / not sure)
6. Anything you want me to avoid or be careful with? (Injuries, pain, doctor restrictions — this does not replace medical advice)
7. Have you been told by a doctor to avoid exercise? (Yes / No) — if yes, we ask you to get clearance first
8. What usually stops you from going? (Time / not knowing what to do / low motivation / feeling out of place / other)
9. What would make the next 4 weeks a success for you, in your own words?
10. Best way for me to remind you each Sunday? (Email / community chat)
11. Checkbox: I understand this is general fitness guidance, not medical advice.

## 4. Weekly rhythm (about 2.5 hours/week at 10 members)

- **Sunday message (template):** "Hi [name] — this week: [Mon A / Wed B / Fri C]. Focus: [one cue]. Reply with the days you're planning to train. If a day gets skipped, move it, don't drop it."
- **Midweek check-in prompt (chat):** "One word for how the week is going, and what's getting in the way?"
- Reply to each member briefly (target 3–5 min each).
- Note blockers in a log; they feed the weekly improvement.
